| القاعدة | النتائج وقت التفعيل | المعالجة |
|---|---|---|

إضافة إلى ذلك أُصلحت **6 أخطاء قائمة** من قواعد React Compiler (خطأ مستوى الأساس):
- `react-hooks/refs` ×1 في `google-id-button.tsx` — تحديث ref كان أثناء التصيير، نُقل إلى `useEffect`.
- `react-hooks/set-state-in-effect` ×5 (`google-id-button`، `command-palette`، `sb-account-screen` ×2، `sb-admin-screen`) — أعيدت الهيكلة على النمط الموصى به: **جلب نقٍّ بلا setState** (`fetchData`) + **تطبيق النتيجة من متابِعات async** (`apply`) + إعادة تحميل عبر معالجات الأحداث، مع حارس `cancelled` لتفادي التحديث بعد فك التركيب. في `command-palette` حُذف الـ effect وأُسندت إعادة التصفير إلى دالة إغلاق موحدة `changeOpen` تغطي كل مسارات الإغلاق (Esc/اختيار/اختصار/زر خارجي).

**النتيجة النهائية: `bun run lint` نظيف تماماً (0 أخطاء، 0 تحذيرات) بلا أي إيقاف للقواعد الحرجة.**
