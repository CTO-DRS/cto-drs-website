# ملفات موقع CTO-DRS

## ما تتضمنه الحزمة

- `published-site/`: جميع ملفات النسخة المنشورة في مستودع cto-drs.com، وعددها 169 ملفاً، بما فيها HTML وJavaScript وCSS والصور والخطوط وبيانات النشر.
- `development-source/`: جميع الملفات المتتبعة في مستودع التطوير الخاص cto-drs-website، وعددها 237 ملفاً، بما فيها مشروع Next.js/TypeScript، الواجهات وAPI ومخطط Prisma والاختبارات وسكربتات البناء.
- `git-history/`: حزمتا Git Bundle تتضمنان سجل Git والمراجع التي نُزّلت من كل مستودع. لا تتضمنان إعدادات تسجيل الدخول أو توكن GitHub المستخدم للتنزيل.
- `manifest.json`: هوية المستودعين والـ commits وتواريخها وقائمة كل الملفات وبصماتها.
- `checksums.sha256`: بصمات SHA-256 لجميع الملفات الأخرى داخل الحزمة.

المجموع: 406 ملفاً حالياً من المستودعين، إلى جانب ملفات التحقق وسجل Git.

## ما تم التحقق منه

- الصفحة الرئيسية في نسخة النشر تطابق صفحة https://cto-drs.com المنزّلة حرفياً بالبايت.
- لا توجد Git submodules أو مؤشرات Git LFS معلقة في النسختين.
- كلا المستودعين نظيف بعد التنزيل دون أي تعديل.
- فحص محلي لمراجع أصول HTML/CSS في نسخة النشر لم يجد أصولاً محلية مفقودة؛ الخدمات الخارجية ومراجع RSC ليست ضمن هذا الفحص.
- تم التحقق من صلاحية حزم Git Bundle واختبار سلامة ZIP.

- نسخة النشر: commit `f2c0823ba3bc986188d4468d2618c6001884ac88` بتاريخ `2026-11-06T11:49:50+00:00`.
- مصدر التطوير المحفوظ: commit `fd15743cba8db3ae2c6fd711cc4a0b79004723c0` بتاريخ `2026-11-01T09:28:47+00:00`.

مصدر التطوير المحفوظ أقدم من آخر نشر؛ لا يوجد ضمان بأن إعادة بنائه تنتج النسخة المنشورة الحالية حرفياً.

هذه نسخة كاملة من **الملفات المتتبعة التي أمكن الوصول إليها في المستودعين**، وليست نسخة استعادة كاملة لكل الخدمات التشغيلية. لا تشمل بيانات المستخدمين أو قواعد الإنتاج أو إعدادات وأسرار بيئات التشغيل غير المحفوظة في Git، ولا بيانات Supabase أو الخدمات الخارجية. نطاق academy.cto-drs.com موجّه إلى Vercel ومشروعه المنفصل غير مشمول؛ صفحة التعريف بالأكاديمية الموجودة ضمن الموقع الرئيسي مشمولة.

لم تُنزّل تطبيقات APK والمستودعات الأخرى المرتبطة بالموقع، لأنها منتجات مستقلة وليست ملفات تشغيل الموقع الرئيسي.

## فتح النسخ واستعادة سجل Git

يمكن خدمة مجلد `published-site/` عبر أي خادم ملفات ثابت يدعم صفحات الفهرس. قد تتطلب وظائف تسجيل الدخول والنماذج والخدمات الخارجية اتصالاً وإعدادات تشغيل صحيحة.

مصدر التطوير يتضمن README وأوامر التشغيل في package.json. لم يتم تثبيت الحزم أو البناء أو تشغيل الاختبارات؛ لا تشغّل أوامر تهيئة/إعادة ضبط قاعدة البيانات على الإنتاج دون مراجعتها.

لاستعادة مستودع مع تاريخه:

```bash
git clone git-history/cto-drs.com.bundle restored-published
git clone git-history/cto-drs-website.bundle restored-source
```

احتفظ بالحزمة بشكل خاص لأنها تتضمن مشروع تطوير خاصاً وتاريخه. لم يتم تعديل الموقع أو DNS أو صلاحيات الوصول أو أي إعداد في Spaceship أو GitHub.
